## 📂 هيكل التسليم

| المجلد | المحتوى |
|---|---|
| `reels/` | ريلز وتيك توك · 9:16 · MP4 |
| `posts/` | منشورات إنستغرام · 1:1 و 4:5 |
| `carousels/` | كاروسيلات متعددة الشرائح |
| `stories/` | ستوريز · 9:16 |
| `ads/` | إعلانات مدفوعة (كل المقاسات) |
| `linkedin/` | محتوى لينكدإن |
| `covers/` | أغلفة فيسبوك · يوتيوب · إكس |
| `motion/` | موشن جرافيك وانتقالات الشعار |
| `source-files/` | ملفات المصدر (Figma · PSD · AE · PR) |

**التسمية:** `YYYY-MM-DD_النوع_وصف-قصير.ext`
مثال: `2026-08-01_reel_قهوة-الترحيب.mp4`
