## 3. البوابات الثلاث

### البوابة A — QA (عينة 20%)

**المالك:** عالم أبحاث  
**حجم العينة:** `ceil(عدد أصول الدفعة × 0.20)`، وبحد أدنى أصلين عندما تكون الدفعة ≥2.

يفحص لكل أصل مختار:

- العلامة المائية في المنتصف باستخدام الرمز الرسمي، شفافية 15–25%.
- الشعار الكامل الرسمي في الموضع التصميمي الصحيح.
- التسمية `YYYY-MM-DD_النوع_وصف-قصير.ext`.
- ملف Markdown مرافق يغطي المجموعة/الأصل: العنوان، الكابشن، 15–20 هاشتاغاً، CTA، الإنجليزية، والمصادر.
- لا أسعار إلا صيغة معتمدة، ولا ادعاءات/أرقام غير موثقة.
- لا وجوه مولدة ممزوجة بالواقع.
- الفيديو 30fps/H.264، Hook ≤1.5s، مفهوم بلا صوت، وقص يتتبع الحركة.
- الستوري تراعي 250px أعلى و300px أسفل.

**الحكم:** Pass / Pass with corrections / Fail، مع مسارات العينة وcommit المراجعة.

### البوابة B — اتساق العلامة

**المالك:** استراتيجي العلامة التجارية

- النبرة عربية فصيحة، دافئة وواثقة، بلا تكلف.
- العنوان ≤5 كلمات، وتسلسل بصري واضح على شاشة صغيرة.
- الألوان ضمن الكحلي `#1A254C`، الذهبي الرملي `#D8A873`، العاجي `#F5F0E8`، والفحمي `#121212`.
- الفخامة هادئة ومنضبطة؛ لا زخرفة أو ظلال ثقيلة أو ازدحام.
- الخط العربي أنيق غير مزخرف، مع هرمية ثابتة ومقروئية عملية.
- لا إعادة رسم أو تدوير أو إعادة تلوين للشعار خارج النسخ الأصلية.
- الرسالة تتسق مع الجمهور ولا تحصر العلامة في فئة واحدة.

**الحكم:** Approved / Revise، مع سبب محدد لا وصف ذوقي عام.

### البوابة C — موضع النشر والـBacklog

**المالك:** مدير المنتج الثاني

- يحدد المنصة، الهدف (وعي/ثقة/تفاعل/تحويل)، الجمهور، وترتيب النشر.
- يمنع تتابع قطعتين متشابهتين بصرياً أو موضوعياً.
- يوازن كل 10 قطع بين: خدمة، تجربة، ثقة، تفاعل، تحويل.
- يسجل حالة الدفعة: Planned → In production → QA → Brand review → Scheduled → Published/Archived.

## 5. تحويل البحث التنافسي إلى Brief تصميم

لا يقبل تسليم بحث جديد دون 3–5 بطاقات تطبيق، كل بطاقة تتضمن:

| العنصر | الوصف |
|---|---|
| النمط المرصود | ما الذي فعله المنافس أو المرجع؟ |
| المصدر | URL + تاريخ الوصول |
| سبب الملاءمة | لماذا يخدم كيف الضيافة؟ |
| الترجمة الإبداعية | Reel/Post/Carousel محدد، لا توصية عامة |
| الخامة المتاحة | فئة أو ملفات من الخزنة |
| مقياس النجاح | حفظ/مشاهدة/نقر/رسالة أو معيار جودة |
| خطر التقليد | كيف نحافظ على أصالة العلامة؟ |

## 8. بوابة اعتبار الدفعة نهائية

لا توصف الدفعة بأنها «نهائية» إلا إذا:

1. رُفعت كل الأصول وmetadata إلى المستودع.
2. نجحت عينة QA 20% أو أُغلقت تصحيحاتها.
3. حصلت على Approved من استراتيجي العلامة.
4. سُجل موقعها في backlog/جدول النشر.
5. لا يوجد تكرار غير مبرر مع المكتبة الحالية.
6. سُجلت المصادر وخطوط التصميم والنسخ المعتمدة.

بهذا يبقى الإنتاج سريعاً ومتوسعاً، لكن كل دفعة قابلة للتتبع والمراجعة والجدولة بدلاً من تراكم ملفات غير مصنفة.
